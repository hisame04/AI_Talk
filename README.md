# AI_Talk

初音ミクと会話するためのUnityアプリです。

## Local-Only Assets

以下のフォルダ内のファイルは、ライセンスの都合によりgitの追跡対象から外しています。

- `Assets/3Dmodel/`
- `Assets/Motion/`
